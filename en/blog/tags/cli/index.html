Security Fix: Media Path Alias Sandbox Bypass

Section titled “Security Fix: Media Path Alias Sandbox Bypass”

This is the most important fix in this release.

Problem: Outbound tools and message actions could bypass media-root restrictions through mediaUrl or fileUrl alias fields, accessing files outside the sandbox. A malicious prompt injection could trick an agent into reading /etc/passwd via fileUrl and sending it externally.

Root cause: Security boundary checks only covered primary path fields. Alias fields were unchecked.

Impact: Multi-tenant OpenClaw deployments are at highest risk. Single-user setups are less exposed but should still upgrade.

Path traversal via alias fields is a classic web security issue. Jupyter Notebook and Code Server have both had similar vulnerabilities. This fix unifies all path fields under the same security check.

Outbound Media/Local Files: Policy Alignment

Section titled “Outbound Media/Local Files: Policy Alignment”

Sending host-machine local files failed when workspaceOnly was off. File sending used different permission logic than file reading. If you worked around this by copying files into the workspace, you can remove that workaround.

What is Fabric?

Section titled “What is Fabric?”

Fabric is an open-source framework that organizes and manages AI prompts—called Patterns—in a modular, reusable system. Unlike scattered prompts across various tools and platforms, Fabric provides a centralized, command-line-first approach to collecting, organizing, and executing AI solutions.

Section titled “1. Pattern-Based Architecture”

FAQ

Section titled “FAQ”

Q: Is Fabric free to use? A: Yes, Fabric is MIT licensed. However, you need API keys for AI providers, which may have costs.

Q: Can I use Fabric without internet? A: Yes, with local models through Ollama.

Q: How do I contribute patterns? A: Submit a pull request to the Fabric repository with your pattern in the data/patterns directory.

Q: Does Fabric store my data? A: Fabric processes data locally. Data is sent to AI providers based on your configuration.

Q: Can I use multiple models in one workflow? A: Yes, you can chain patterns with different models using shell pipes.
