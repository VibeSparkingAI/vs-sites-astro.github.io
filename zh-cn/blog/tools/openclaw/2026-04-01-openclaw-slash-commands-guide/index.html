OpenClaw 斜杠命令完全指南

2026年4月1日
Vibe Sparking

适用版本：OpenClaw 2026.3.x+

OpenClaw 的斜杠命令是你与 Gateway 直接交互的快捷通道——不经过模型，不消耗 token，即时执行。掌握它们，就是掌握了 OpenClaw 的操控面板。

一、命令体系概览

Section titled “一、命令体系概览”

OpenClaw 的命令分三层：

类型特征示例
Commands独立消息，Gateway 直接处理/help、/stop、/kill
Directives可内联在消息中，模型看不到/think、/model、/fast
Text-only仅文本聊天可用! ls -la、/compact

核心区别： Directive 单独发送时会持久化到 session；嵌在普通消息里只对当条生效。这个区别很重要——后面会反复提到。

权限模型

Section titled “权限模型”

不是所有人都能用命令。授权链路：

  1. 如果配了 commands.allowFrom → 只看这个，其他全忽略
  2. 否则 → channel allowlist + pairing + commands.useAccessGroups
  3. 未授权 sender 的命令消息 → 静默丢弃，inline /... 当普通文本

快速路径

Section titled “快速路径”

Command-only 消息（整条只有命令）走 fast path：不进队列、不过模型、不需要 @提及（群聊中）。这意味着 /stop 永远能立即生效，哪怕模型正在疯狂输出。

二、日常高频命令

Section titled “二、日常高频命令”

/status — 你的仪表盘

Section titled “/status — 你的仪表盘”

返回当前 session 的完整状态：模型、provider 用量/配额、thinking 级别、elevated 状态等。

实战场景：

  • 检查额度： 跑完一个大任务后 /status 看看 Claude 还剩多少额度
  • 确认配置： 切完模型后 /status 确认生效
  • 排查异常： agent 回复变慢了？/status 看看是不是 thinking 被调高了

技巧： /status 是 inline shortcut，可以写 帮我写个脚本 /status——先返回状态，消息照常处理。

十三、注意事项速查

Section titled “十三、注意事项速查”
要点说明
Directive 持久化单独发 = 持久化；嵌在消息里 = 仅当条生效
群聊安全/reasoning 和 /verbose 会暴露内部信息
权限优先级配了 allowFrom 就只看它
快速路径Command-only 消息不进队列、不过模型
Config 类默认关/config、/debug、/mcp、/plugins、/bash 都要手动启用
/elevated full跳过所有审批，极度危险
/kill 无确认立即执行
